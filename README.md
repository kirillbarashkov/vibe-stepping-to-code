# vibe-stepping-to-code

Материалы к каналу **«Кир-и-Мёфа-вайбкодят»** — https://t.me/vibeSteppingToCode

Здесь лежит то, что не влезает в пост: полные разборы, скрипты, которые запускаются
как есть, и подробности, которых в Telegram не покажешь.

## Как устроено

- один пост = одна папка `posts/<номер>-<slug>/`;
- `README.md` внутри папки — полный разбор (уровень 3);
- рядом — рабочие скрипты без внешних зависимостей;
- в канале — короткая версия поста и ссылка сюда.

## Уровни

| Метка | Кому | Что внутри |
|---|---|---|
| 🟢 уровень 1 | впервые строит с агентом | зачем и один шаг, который работает |
| 🟡 уровень 2 | уже запускал, упёрся в стену | причина, фикс, чем проверить |
| 🔴 уровень 3 | отлаживает сам | механика, граничные случаи, код |

Пост в канале помечен всегда. Детали уровня 3 живут здесь.

## Границы

В репозитории нет клиентских материалов, токенов и чужих данных. Примеры конфигов
обезличены, ключи — только заглушками вида `123456:AA...`.
